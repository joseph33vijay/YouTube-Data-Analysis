# YouTube Data Analysis 📊

This project analyzes YouTube Trending Video Data using Python, Pandas and Matplotlib.

## 🔹 Features
- Data Cleaning
- Removing Duplicates
- Handling Missing Values
- Category Mapping using JSON
- Most Viewed Video
- Top 5 Categories Visualization

## 🔹 Technologies Used
- Python
- Pandas
- Matplotlib

## 🔹 Dataset
Dataset not included due to size limitations.

Download from:
https://www.kaggle.com/datasets/datasnaek/youtube-new

Place `INvideos.csv` inside the project folder before running the program.
